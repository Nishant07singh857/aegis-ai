# SPECTATOR COVERAGE — What BGMI Spectator Mode Shows vs What AEGIS Captures

**Phase 24 · W1 — Spectator Signal Coverage Audit**
**Date:** 2026-10-20 · **Method:** code-verified. Every "yes" below cites the file that
implements it (grep/read of `backend/app/`, `frontend/`). Doc claims were **not**
trusted — where `docs/BGMI_TERMS_AZ.md` or other docs claim a detection the code
does not implement, it is flagged in §4.
**Worldview (standing directive):** spectator/observer mode ONLY. There is **no**
game API, no telemetry, no server feed. Anything not visible on an observer
phone screen (or tappable by a human spotter watching one) does not exist for AEGIS.

**Status key:** `COVERED` = captured → stored → shown/consumed end-to-end ·
`PARTIAL` = some legs of the chain exist, named leg missing · `GAP` = no live
capture (a class/table/UI shell may exist on disk) · `INCOMING-P23` = Phase 23
work in flight (not audited here).

**Storage shorthand:** almost all vision/feed events persist generically via the
event bus → `event_store` table (`backend/app/core/event_bus.py::_persist_event`).
A dedicated table is named only where a live writer actually writes it.
"In-memory only" means state lives in an agent/service and dies on restart.

**Wired-live vision set (the ground truth for all rows below):**
`backend/app/vision/runtime.py` registers exactly 10 detectors —
`KillFeedDetector`, `AliveCountReader`, `ZoneTimerReader`, `TeamStatusReader`
(`vision/detectors/hud.py`), `HPBarDetector`, `UtilityDetector`, `MinimapReader`,
`ZoneDetector`, `HealingDetector`, `LootDetector` — on **one** capture source
(`VisionCaptureService.SOURCE_ID = "vision0"`, one `AEGIS_VISION_OBSERVER_SLOT`).
Deliberately **not** wired (runtime docstring): `VehicleDetector`,
`WeaponDetector`, `KnockDetector`, `PlayerTracker`, legacy `AliveCounter` /
`kill_feed_ocr.py` (need PaddleOCR/ultralytics, not installed; wiring them
would emit untruthful data). Bus consumer for vision events:
`backend/app/services/vision_intelligence/service.py` (Phase 22 subscriber;
observer-slot → team attribution via `observer_slots` DB, unmapped = dropped,
never guessed).

## 3. Spectator Limitations Register

What spectator mode **fundamentally cannot provide** — no detector, model, or
future phase changes these; they are properties of watching a rendered client.

| # | Limitation | Why it's fundamental | Standing workaround | Stated honestly in AEGIS docs/UI today? |
|---|---|---|---|---|
