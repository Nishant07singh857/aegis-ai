3. **Map rotation:** Rondo opener, then Erangel ×3, Miramar ×2 (BMSD GF used Erangel/Miramar per the countdown screen).
4. **WWCD as a table column** in the overall ranking (BMSD GF's overall table used chicken count — same data, different column label).
5. **Venue integration:** Jaipur crowd shots, "COME ON JAPUR" chants, fan-zone (photo booth/Challenger Zone/merch) preshow content — heavier IRL-event packaging than the BMSD VOD.
6. **MVP/Eliminator awards** referenced on-air ("eliminator of the tournament. Jordan", "MVP of that game… Slug") — individual awards are a bigger on-broadcast element here.
7. **Opening ceremony + full 16-team walkouts** with a dedicated stage host (separate from casters).
